## 🐳 الصورة

```text

```

## 🚀 التشغيل

```bash
npm run {{STARTUP_SCRIPT}}
# أو
pnpm run {{STARTUP_SCRIPT}}
```

**المزايا:** SSR · SSG · npm · pnpm عبر Corepack

## ⚙️ المتغيرات

| المتغير | الافتراضي | مطلوب |
|---------|-----------|-------|
| `PACKAGE_MANAGER` | `npm` | نعم |
| `STARTUP_SCRIPT` | `start` | نعم |
| `PNPM_VERSION` | `10.12.1` | نعم |
| `NODE_PACKAGES` | فارغ | لا |
